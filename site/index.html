How it works

  1. Read

    Hermes Desk reads each incoming message in Vietnamese, along with the conversation history for that customer.

  2. Route

    It sorts the message as a new lead, a complaint or a billing request, marks how urgent it is, and assigns it to the right person.

  3. Draft for approval

    It writes a reply in the coordinator's tone. Nothing is sent until a person approves it.

    Built with Claude
    
      
    
        
      
          
    • Model. The prototype on this page calls Claude Haiku (claude-haiku-5-5) through the Claude Messages API, from a serverless function, on Hermes Desk's own Claude API account.
      • 
          
    • Structured output. Claude answers through a single tool, route_message, which returns five fields: category, urgency, who to route to, a one-line English summary and a Vietnamese draft reply. If the answer does not come back in that shape, the function returns an error rather than a made-up result.
      • 
          
    • Guardrails. Messages are capped at 600 characters, usage is rate-limited per visitor and per day, and Claude is told never to promise prices, availability or dates the coordinator has not given.
      • 
          
    • A person approves every reply. The AI never speaks to a customer on its own.
      • 
          
    • Built with Claude. The system design, the Zalo sync and the lead ledger behind our internal tool were largely written with Claude.
      • 
          
    • Today and next. The internal tool sorts contacts with fixed rules first, such as Zalo tags and known contact lists, and the few contacts no rule covers are classified by Gemini Flash. Next, we move classification and drafting in the internal tool onto the Claude API.
      • 
          
    • Source. The prototype code is public on GitHub.

    FAQ
    
      
    
        
    Does Hermes Desk send messages on its own?
    No. It sorts each message and writes a draft. A person reads, edits and approves every reply before anything is sent.
    
        
    Which AI does it use?
    The demo on this page runs on Claude Haiku through the Claude API. Our internal tool sorts contacts with fixed rules first and uses Gemini Flash for the few contacts no rule covers; we are moving that step onto Claude.
    
        
    What languages does it handle?
    It reads casual Vietnamese chat and drafts replies in Vietnamese. Each message also gets a one-line English summary.
    
        
    Is the text I type into the demo saved?
    No. It is sent to the Claude API to be sorted and answered, shown to you, and not stored by Hermes Desk. Please use example messages, not real customer details.
    
        
    How do I start?
    Request a spot in the free pilot. We set Hermes Desk up for your desk, then you choose the Coordinator or Team plan if you want to keep it.
    
        
    Can I have my data deleted?
    Yes. Email tung@hermesdesk.dev and we act on the request within 72 hours. See the privacy page.
